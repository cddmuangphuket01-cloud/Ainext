โปรดตั้งค่า API Key อย่างน้อย 1 ผู้ให้บริการ ก่อนเริ่มใช้งาน AI Chat

ข้อควรทราบ
เรียก API ของผู้ให้บริการโดยตรงจากเบราว์เซอร์เพื่อการทดสอบ/ใช้งานภายในหน่วยงาน — คีย์ API จะถูกเก็บไว้ใน Local Storage ของเครื่องนี้เท่านั้น หากนำไปใช้งานจริงในวงกว้าง แนะนำให้ทำ Backend Proxy เพื่อความปลอดภัยของคีย์ และหลีกเลี่ยงปัญหา CORS จากผู้ให้บริการบางราย
